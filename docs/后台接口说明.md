# Koyun 客户端 · 数据管理后台接口说明

> 给以后建设"数据管理网站"用。App 端已经全部做好，后台按本文实现这 3 个接口即可接入。
> 后台地址和密钥在**编译时注入**（不写进公开仓库）：
>
> | 编译参数 | 含义 | 生成方式 |
> |---|---|---|
> | `KOYUN_STATS` | 后台地址，例如 `https://admin.example.com`（必须 https） | `python3 tools/encode_domains.py "https://admin.example.com"` |
> | `KOYUN_STATS_KEY` | 客户端密钥（随便一串随机字符） | `python3 tools/encode_domains.py "你的密钥"` |
>
> Windows：GitHub 仓库 Secrets 加同名两项；安卓：编译机 `/opt/kvbuild/keys/app.env` 加同名两行。
> **不设置 = 功能关闭**，App 不会收集、不会发送任何数据。

---

## 通用约定

- 所有请求都带以下请求头：

  | 请求头 | 说明 |
  |---|---|
  | `X-Koyun-Key` | 客户端密钥，后台校验，不对就返回 401 |
  | `X-Koyun-Device` | 匿名设备编号（32 位十六进制，首次启动随机生成，和账号无关） |
  | `User-Agent` | `KoyunVPN/1.0.3` |
  | `Content-Type` | `application/json` |

- 成功返回 HTTP 2xx（内容随意，App 只看状态码），失败返回其它状态码。App 失败后会保留数据下次重发。
- 每次请求都带 `device` 对象：

  ```json
  {
    "id": "9f2c1e...（设备编号）",
    "platform": "windows | android | macos | ios",
    "os_version": "\"Windows 10 Pro\" 10.0 (Build 19045)",
    "app_version": "1.0.3",
    "core_version": "1.14.4",
    "locale": "zh-CN"
  }
  ```

## 1. 事件上报 `POST /api/v1/client/events`

App 把事件存在本机，每 5 分钟或攒满 20 条时批量发送（每批最多 50 条）。

```json
{
  "device": { ... },
  "events": [
    { "type": "app_start", "ts": 1762156800, "data": {} },
    { "type": "connect_ok", "ts": 1762156810,
      "data": { "node": "auto:[anytls]🇭🇰香港D01-1X", "protocol": "anytls", "tun": false, "route": "rule", "ms": 1830 } },
    { "type": "connect_fail", "ts": 1762156900,
      "data": { "node": "[Hy2]🇯🇵日本D13-1X", "protocol": "hysteria2", "tun": true, "route": "global", "error": "..." } },
    { "type": "disconnect", "ts": 1762160000,
      "data": { "node": "...", "duration_s": 3190, "up_bytes": 10485760, "down_bytes": 524288000 } },
    { "type": "crash", "ts": 1762160100, "data": { "error": "...", "stack": "...（最多 4000 字）" } }
  ]
}
```

| type | 含义 | 可做的统计 |
|---|---|---|
| `app_start` | App 启动 | 日活 / 版本分布 / 系统分布 / 语言分布 |
| `connect_ok` | 连接成功，`ms` = 连接耗时 | 各节点成功率、平均连接耗时 |
| `connect_fail` | 连接失败，`error` = 失败原因 | 哪个节点 / 协议经常失败，失败原因排行 |
| `disconnect` | 主动断开，带本次时长和流量 | 平均使用时长、各节点流量 |
| `crash` | 程序报错 | 崩溃排行，定位 Bug |

`ts` 为 Unix 秒。`node` 为节点名，`auto:` 开头表示"自动选择"及当时实际用的节点。

## 2. 用户反馈 `POST /api/v1/client/feedback`

用户在"用户中心 → 反馈问题"里主动提交。

```json
{
  "device": { ... },
  "content": "香港节点晚上很卡",
  "contact": "用户填写的联系方式（默认填好了账号邮箱，可改）",
  "email": "账号邮箱（本地导入模式为 null）",
  "logs": "最近的内核运行日志（用户可选择不附带，此时为 null）",
  "extra": {
    "os": "windows ...",
    "connected": true,
    "node": "auto",
    "tun": false,
    "route": "rule",
    "nodes_count": 18,
    "plan": "标准套餐",
    "local_ip": { "ip": "...", "country_code": "CN", "city": "Shanghai", "asn": 4134, "org": "Chinanet",
                  "fraud_score": 12, "residential": true, "broadcast": false },
    "proxy_ip": { ... 同上，未连接时为 null ... }
  }
}
```

返回 2xx 后 App 提示"已收到您的反馈"。后台没开通时，App 的"反馈问题"会改为打开网站工单页面。

## 3. 远程配置 `GET /api/v1/client/config?platform=windows&version=1.0.3`

App 启动 5 秒后、以及用户点"检查更新"时请求。**优先于 GitHub**（国内访问更快）；请求失败或没有 `latest` 字段时，App 自动改查 GitHub Releases。

```json
{
  "latest": {
    "version": "1.0.4",
    "notes": "更新说明（纯文本，可多行）",
    "page": "https://...（下载页面）",
    "downloads": {
      "windows": "https://.../Koyun-1.0.4-windows-x64-setup.exe",
      "android": "https://.../Koyun-1.0.4.apk",
      "macos": "https://.../Koyun-1.0.4.dmg"
    }
  }
}
```

- `version` 比当前版本新时，App 弹窗提示更新。
- Windows 会下载 `downloads.windows` 后静默安装并自动重启；其它平台用浏览器打开下载地址（没有则打开 `page`）。
- 以后需要更多远程开关（公告、强制更新最低版本等）可以在这个接口里继续加字段，App 再对应升级。

## 建议的后台数据表（参考）

| 表 | 字段 |
|---|---|
| devices | id, platform, os_version, app_version, locale, first_seen, last_seen |
| events | id, device_id, type, ts, data(JSON), ip（请求来源 IP）, created_at |
| feedback | id, device_id, content, contact, email, logs, extra(JSON), status(待处理/已处理), created_at |
